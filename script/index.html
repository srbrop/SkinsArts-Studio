Generador de Scripts Node.js

Genera tu script Node.js personalizado (Automático, Guiado con la tecla Z o Captura HD).

AutoNameMC-Guiado.js 

                

            


            

                

                    
Instrucciones de Uso

                    Brave · Chrome · Edge
                


                

                    Requisitos Clave:
                    Guarda tu carpeta fuera de OneDrive/Drive (ej. en C:\) y desactiva extensiones de NameMC (NameMC Unlock/Extras) para la captura HD.
                


                

                    

                        

                            1
                            Extraer las 27 skins y guardar tu script
                        

                        

                            Descarga tu .zip en el Generador de Skins, extrae las 27 imágenes en tu carpeta local y guarda ahí mismo el archivo AutoNameMC-Guiado.js descargado desde la izquierda.
                        

                    


                    

                        

                            2
                            Instalar Node.js y Puppeteer en CMD
                        

                        

                            Instala Node.js LTS. En tu carpeta, haz clic en la barra de direcciones superior, escribe cmd y presiona Enter. Ejecuta:
                        

                        

                            npm init -y && npm install puppeteer
                            
                        

                    


                    

                        

                            3
                            Abrir Navegador en Modo Debug (Windows + R)
                        

                        

                            Cierra todas las ventanas de tu navegador, presiona Windows + R y pega el comando del navegador que uses:
                        

                        

                            
                            
                            
                        

                        

                            • Pestaña 1: Abre Minecraft.net (Cambiar aspecto). Importante: Selecciona manualmente ahí el tamaño de brazos de tu skin (Clásico o Delgada), ya que el script no cambia esa opción por ti.

                            • Pestaña 2: Abre tu propio perfil en NameMC (es.namemc.com/profile/TU_USUARIO).
                        

                    


                    

                        

                            4
                            Ejecutar el Script en CMD
                        

                        

                            Regresa a la consola CMD de tu carpeta y ejecuta el comando de inicio (el capturador ajusta automáticamente el zoom al 100% sin importar si tu pestaña estaba en 80% o 90%):
                        

                        

                            node AutoNameMC-Guiado.js
